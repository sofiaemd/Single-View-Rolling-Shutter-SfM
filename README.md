# Single-View-Rolling-Shutter-SfM

This code is supplementary material for "Single-View Rolling Shutter SfM"

## Prerequisites

We use Macaulay2 and Julia for the computations.

The required packages for running this software with Julia are: LinearAlgebra.jl, AbstractAlgebra.jl, Oscar.jl and HomotopyContinuation.jl

## Section C

All the computations mentioned in Section C can be found in the folder called Section_C.

## Practical reconstruction

The code for practical implementations can be found in the folder Practical_Reconstructiuons. The files are named following the convention di_delj_n1..nl where i is the value for d, j is the value for delta and n1 to nl are the amount of points sampled in each line.
